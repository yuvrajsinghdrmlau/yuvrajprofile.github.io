# Space Edition design notes

Visual direction: a quiet, professional mission-control interface with midnight navy surfaces, icy-blue constellation links, lime highlights, restrained monospace labels, and generous typography. Space imagery is decorative; this is still an AI / ML engineering portfolio.

All visible project art besides the hero is code-native CSS/SVG illustration. The scan, thermal target, waveform, and mini API panels are conceptual decoration, not fabricated project screenshots, measured outputs, or actual instrument telemetry.

The hero is an original fictional-planet illustration generated with the built-in image-generation tool (not the CLI). Final optimized project asset: `source/space-hero.webp`. The build embeds that asset in `publish/index.html`; there are no third-party image or font requests.

## Full final generation prompt

Use case: stylized-concept. Asset type: original cinematic background for an AI engineer's space-themed portfolio website, not a website mockup. Primary request: a majestic dark blue planet seen from orbit against an almost-black navy starfield. Composition: wide 16:9 horizontal image; a large detailed planet occupies the right 55 percent of the frame, its upper rim catching thin icy cyan sunlight, lower hemisphere dissolving into shadow; the left 45 percent is calm nearly-black negative space suitable for readable white website text. Delicate atmospheric glow, sparse distant stars, a very subtle pale ring/orbital arc around the planet; refined realistic 3D space art with deep shadows and restrained contrast. Palette: midnight navy, steel blue, ice cyan, no purple. Planet surface: subtle rocky/cloud textures, no recognisable continents. Mood: quiet, ambitious, technical, premium editorial. No people, no spacecraft, no logos, no words, no UI, no watermarks. This is an illustrative fictional planet, not a scientific diagram.
