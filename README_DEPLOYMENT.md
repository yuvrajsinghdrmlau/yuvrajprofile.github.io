# Publish on a Different GitHub Account

This package is ready for GitHub Pages. Upload the **files inside this folder**, not the folder itself.

## Recommended: personal portfolio address

This creates `https://YOUR_USERNAME.github.io`.

1. Sign in to the GitHub account that should own the portfolio.
2. Go to `https://github.com/new`.
3. Name the repository exactly `YOUR_USERNAME.github.io`.
   - Example: if the new username is `yuvraj-ai`, use `yuvraj-ai.github.io`.
4. Select **Public**.
5. Leave README, `.gitignore`, and license unchecked, then select **Create repository**.
6. On the new repository page, select **uploading an existing file**.
7. Extract the ZIP first, then upload every file from the extracted folder.
8. Enter `Publish portfolio` as the commit message and select **Commit changes**.
9. Go to **Settings → Pages**.
10. Under **Build and deployment**, choose:
    - Source: **Deploy from a branch**
    - Branch: **main**
    - Folder: **/(root)**
11. Select **Save** and wait a few minutes.
12. Open `https://YOUR_USERNAME.github.io` in a private/incognito window.
